## 必跑回归

按[交接入口](README.md)运行后端测试、前端类型检查和构建。修改 IPC/Rust 时跑 Rust 健康测试；修改资源、安装配置或 Python 定位时重建并安装验证。所有 SQLite 测试使用临时应用数据目录，不能修改用户的 `%APPDATA%\MindFlip` 数据。

第一迭代尚无逐项人工记录的 UI 健康成功、后端不可用、超时与重试，在下一轮首轮桌面回归中补记。当前后端是单请求子进程；失联测试通过当前测试会话的无效 `MINDFLIP_PYTHON` 路径制造，测试结束后恢复，不修改持久用户环境变量。

## 新功能测试编写规则

- 先覆盖领域规则与数据迁移，再覆盖 API 契约和 UI 状态。
- 新增迁移须验证空库升级、旧库升级、重复启动、数据保留及失败处理。
- 新增 IPC 方法须验证正确响应、无效请求、超时/后端失联与错误码；契约样例、Rust/Python 类型和前端类型必须一致。
- 记录未执行、跳过和失败项；不要将“未观察到问题”写成“测试通过”。
