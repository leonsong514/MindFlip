## 1. 验收规则与环境

本方案逐条对应用户提供的 Issues #5–#8 共 **17 条 AC**。以下是待实施的验证设计，不代表已有测试或结果。每条 AC 的实际命令、退出码、GitHub Actions 链接及未执行原因写入[验证记录](03-verification.md)。Windows 为本地基线；CI 所选 runner、Node/Python 版本应与锁文件和实际工具兼容，并记录差异。
